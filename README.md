# 语燕输入法 K版

> 本项目基于语燕输入法，由 Gemini 辅助修改完成，本人不会编程，连 `Hello World` 都不会。

---

## 🛠️ 详解设置

### 1. 主题设置
* **主题编辑与导入导出**：新增主题编辑、导入与导出功能，主题文件后缀为 `.yus`。
* **可视化分区编辑**：主题编辑划分了若干个分区，点击任意区域即可修改对应颜色；长按设置项标题可以直接复制色值，可 DIY 的选项非常丰富。
* **单键高级定制**：如果想单独修改输入区的某个按键颜色，可以在 `data` 中找到 `theme` 修改 JSON 文件，可以参考 `{炫彩彩虹拼盘.yus}` 这个主题的处理方式。

### 2. 按键效果
* **定时关闭音效**：新增按键音效的开启时段设置，防止夜间打字音效扰民。
* **丰富音效资源**：增加了按键音效选择，从中抽离并提取了微信、百度等输入法的音效文件。

### 3. 键盘设置
* **编码显示位置**：修改编码显示位置，不再固定显示于工具栏，支持 **【悬浮显示】** 和 **【输入框显示】** 两种模式。
* **持机习惯优化**：新增持机习惯设置。若设置为左手持机，展开候选词及关闭联想词的按钮将自动移至左侧。
* **布局开关**：新增乱序 17 键布局下 **【中筛】** 与 **【左删】** 的独立布局开关。

### 4. 输入设置
* **全键小写**：新增拼音全键键盘小写字母显示，对小学生及初学者更加友好。
* **单次联想**：新增中文联想模式 —— **单次联想**。
* **中英混输**：支持中文 9 键和乱序 17 键下的中英混合输入。

### 5. 语音识别设置
* **离线语音输入**：新增离线语音输入功能，在设置项中配置离线模型下载地址，导入即可离线使用。
* **滑动移动光标**：在 **[按住说话]** 键上方的空白长条区域左右滑动，可以快速移动光标位置。

### 6. 个性化短语
* **常用短语**：新增个性化短语管理功能。

---

## ✨ 其他改善

1. **工具栏对齐**：工具栏中的图标改为居中显示。
2. **图标重绘**：重绘了部分图标，提升视觉精致度。
3. **文本编辑**：文本编辑功能页面完全复刻百度输入法交互。
4. **界面重构**：表情与符号界面进行重构。
5. **剪切板**：剪切板界面完成重构。
6. **候选词体验**：候选词展开后不再遮挡拼音选择。
7. **精简功能**：删除了手写输入功能（识别率较低，遇到不认识的生僻字可直接使用笔画输入）。
